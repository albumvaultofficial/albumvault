Datenschutzerklärung

Stand: 29. Juli 2026

Diese Datenschutzerklärung bezieht sich auf die aktuelle TestFlight-Betaversion von AlbumVault.

1. Grundsatz

AlbumVault wurde so entwickelt, dass Sammlungsdaten grundsätzlich lokal auf dem Gerät verarbeitet werden. Die App verlangt derzeit kein Benutzerkonto.

2. In der App verarbeitete Daten

Die App verarbeitet Angaben zu deiner Stickersammlung, insbesondere gesammelte, fehlende und doppelte Sticker, Fortschritte, Statistiken, Tauschlisten und freigeschaltete Erfolge. Diese Daten dienen ausschließlich der Bereitstellung der App-Funktionen.

3. Speicherung

Die Sammlungsdaten werden derzeit lokal auf dem verwendeten Gerät gespeichert. Eine aktive iCloud-Synchronisierung ist in der aktuellen Betaversion nicht enthalten.

4. In-App-Käufe

In-App-Käufe werden über Apple und den App Store abgewickelt. AlbumVault erhält keine vollständigen Zahlungsdaten. Für die Zahlungsabwicklung gelten die Datenschutzbestimmungen von Apple.

5. TestFlight

Bei der Nutzung einer TestFlight-Version können Apple technische Test- und Diagnosedaten verarbeiten. Dies erfolgt im Rahmen von Apples TestFlight-Dienst.

6. Website und GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf können technisch notwendige Verbindungsdaten, insbesondere die IP-Adresse, durch GitHub verarbeitet werden. Die Website verwendet keine eigenen Analyse-, Werbe- oder Tracking-Dienste und setzt keine selbst eingerichteten Marketing-Cookies.

7. Weitergabe von Daten

AlbumVault verkauft keine personenbezogenen Daten. Eine Weitergabe erfolgt nur, soweit dies für die Nutzung von Apple-Diensten wie App Store, In-App-Käufe oder TestFlight erforderlich ist.

8. Änderungen

Diese Datenschutzerklärung wird angepasst, wenn neue Funktionen wie Cloud-Synchronisierung, Benutzerkonten oder weitere externe Dienste hinzukommen.

9. Kontakt

Während der TestFlight-Phase kann Feedback über die in TestFlight verfügbare Funktion „Beta-Feedback senden“ übermittelt werden.

Du kannst uns auch per E-Mail kontaktieren:

Privacy Policy

Last updated: July 29, 2026

This privacy policy applies to the current TestFlight beta version of AlbumVault.

1. Principle

AlbumVault is designed so that collection data is generally processed locally on the device. The app currently does not require a user account.

2. Data processed in the app

The app processes information about your sticker collection, including collected, missing and duplicate stickers, progress, statistics, trade lists and unlocked achievements. This information is used solely to provide the app's features.

3. Storage

Collection data is currently stored locally on the device. Active iCloud synchronization is not included in the current beta version.

4. In-app purchases

In-app purchases are processed by Apple through the App Store. AlbumVault does not receive full payment details. Apple's privacy terms apply to payment processing.

5. TestFlight

When using a TestFlight build, Apple may process technical beta and diagnostic information as part of the TestFlight service.

6. Website and GitHub Pages

This website is hosted via GitHub Pages. When the site is accessed, GitHub may process technically necessary connection data such as IP addresses. This website does not use its own analytics, advertising or tracking services and does not set custom marketing cookies.

7. Data sharing

AlbumVault does not sell personal data. Data is only shared where required for Apple services such as the App Store, in-app purchases or TestFlight.

8. Changes

This policy will be updated if features such as cloud synchronization, user accounts or additional external services are added.

9. Contact

During the TestFlight phase, feedback can be submitted using the “Send Beta Feedback” option available in TestFlight.
